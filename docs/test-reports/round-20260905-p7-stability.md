## 1. 测试矩阵设计与实现（计划书 §11）

### 1.1 多分辨率与帧率矩阵覆盖
- **覆盖规格**：
  - 1080p (1920×1080)
  - 1440p (2560×1440)
  - 4K UHD (3840×2160)
- **流转验证**：
  - 验证底层 FP16 (`DXGI_FORMAT_R16G16B16A16_FLOAT`) 输入与输出 `DXGI_FORMAT_B8G8R8A8_UNORM` 的严格对齐；
  - 模拟 60fps (16.6ms) 与 30fps (33.3ms) 连续多帧流转，确认管线无时序竞争与丢帧。

### 1.2 色彩与画质定量验收（对比 B0/B2 基准）
- **灰阶连续性 (Ramp 0~1500 nits)**：
  - 对照组 Naive Clamp：白点 (280 nits) 后产生硬切断，高达 81.5% 区域暴白过曝；
  - 色调映射组 (Luma-HuePreserving)：从 0 至 1500 nits 平滑压缩，裁切率降为 0.0%，且通过严格单调递增性检验（无阶调断裂/Banding）。
- **彩色高光色相纯度 (Pure Red 1000 nits)**：
  - 输入 1000 nits 纯红高光（scRGB = 12.5, 0, 0）；
  - 输出像素采样：`R=251, G=0, B=0`，未发生任何偏色、杂色溢出或泛白变灰。
- **SDR UI (280 nits) 与 HDR 峰值高光 (1500 nits) 层次保留**：
  - 同屏 SDR UI 白输出为 235/255，HDR 峰值高光输出为 253/255；
  - 差值 18 个阶调，保证 UI 亮度自然不过曝，同时高光层次清晰可辨。

### 1.3 GPU 性能开销精确基准
使用 D3D11 Timestamp Query 测量 100 帧连续渲染：
- **1080p**：单帧平均耗时 **0.009 ms**（占 4K60 预算 0.05%）；
- **1440p**：单帧平均耗时 **0.015 ms**（占 4K60 预算 0.09%）；
- **4K UHD**：单帧平均耗时 **0.080 ms**（占 4K60 预算 0.48%）；
- **结论**：远低于计划书 `< 1.0 ms` 与 `≤ 2.0%` 的性能红线；全程 GPU 显存流转，0 逐帧 CPU 拷贝。

### 1.4 动态抗扰度与自适应容错
- **动态尺寸自适应 (Dynamic Resize)**：
  - 连续执行 1080p → 4K → 1080p 动态重构，视口与资源自适应更新，无崩溃、无显存泄漏；
- **运行时 HDR 状态切换**：
  - 模拟 HDR On → Off → On 切换，AutoDetect 实时感知并在提升转换与原生旁路之间自适应平滑切换；
- **异常 Fail-Open 防护**：
  - 注入非法/空上下文与空 SRV，内部安全防御拦截并返回 false，未发生宿主崩溃。
