## 架构结论（P4/P5 输入）

1. **帧访问已解决**：FP16 池每帧可取、可 Copy、可统计，性能余量充足（本机 4K@53fps 干跑无压力）
2. **归一化系数实测可得**：scRGB 白 = sdrWhiteNits/80（本机 3.5），P4 Tone Mapping 的 SDR 参考白参数直接从系统读
3. **真实 HDR 高光存在**：max 19.2 ≈ 1539 nits —— BGRA 路径（max 恒 255 截断）确实丢弃了约 5.5 倍动态范围
4. 插入方式（P5 决策）：并行池已证明"我们能拿到 FP16 帧"；剩余问题是把 Tone Map 后的帧**送回** VeRTC——
   候选 a) Hook SDK 的 WGC 帧消费点（把 FP16→BGRA 的我们转换结果作为"帧"供给）；
   候选 b) 外部叠加/虚拟视频路径（兜底）。P4 完成后先在 Harness 内验证算法，再定 P5 集成点。
