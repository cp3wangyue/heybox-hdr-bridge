> 每个通过验证的小黑盒版本记录一份；`config/compat.json` 由本表生成。
> 未知版本默认不写入（AllowUnknownBuild=false）。

| 字段 | 值 |
| --- | --- |
| 客户端版本号 | |

| 关键视频 DLL SHA-256 | |
| 关键签名（符号名 + 偏移 / 语义验证描述） | |
| 已验证捕获 API / 纹理格式 / 编码器输入 | |
| 验证日期 / 验证人 | |
| 遗留问题 | |

## 语义验证要求

所有签名必须有语义验证（例如"目标函数参数中确实出现预期尺寸的 D3D11 Texture"），
避免纯字节签名误命中。签名描述写法示例：

```
signature: <hex bytes> @ <module>+<offset>
semantic: 参数 2 为 ID3D11Texture2D*，Desc.Width==桌面宽, Desc.Format==<已验证格式>
```

## 版本更新复验流程

1. 对比主 EXE / 关键视频 DLL 哈希
2. 哈希变化但符号/签名仍命中 → 只运行 Probe 验证，不直接开启帧替换
3. 重新确认调用链、纹理格式、对象生命周期 → 加入 allowlist
